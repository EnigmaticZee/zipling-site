# zipling.app

The website for Zipling, the Mac archiver. Plain HTML, CSS and JavaScript, served by GitHub Pages from this repository's root at https://www.zipling.app.

- `index.html` is the home page; `benchmarks.html`, `compare.html` and `arca.html` carry the numbers and the engine story; `privacy.html` and `legal.html` the small print.
- `data.js` holds the benchmark results every page draws from.
- Found something wrong on the site or in the app? [Open an issue](https://github.com/EnigmaticZee/zipling-site/issues/new?template=bug_report.yml).

Zipling itself is developed elsewhere; this repository is the site alone.
